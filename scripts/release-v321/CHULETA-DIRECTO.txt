SUBIR LA WEB (elige UNO)
  1) Cloudflare Pages → usa el zip «CLOUDFLARE» (estático puro):
     dash.cloudflare.com → Workers & Pages → Pages → Upload assets →
     arrastra el CONTENIDO del zip → Deploy.
  2) Netlify Drop → usa el zip «ligera»: app.netlify.com/drop y
     arrastra el CONTENIDO del zip.
  3) Hosting propio → descomprime y sirve la carpeta (nginx/caddy/
     python -m http.server).

LA TV EN DIRECTO (opcional)
  PC: cd live-service && npm install && node server.mjs   (puerto 3004)
  Railway/Render: sube el contenido de live-service/ (o el mini-zip
  «SOLO») y despliega con npm start.
  En el juego añade ?relay=http://IP:3004 (o la URL de Railway). Los
  espectadores abren tv.html con el mismo ?relay=.

QUEST (IMPORTANTE)
  El navegador de la Quest exige HTTPS para WebXR: Cloudflare y Netlify
  ya lo dan. En LAN casera usa caddy o ngrok.

PROBLEMAS
  · Arte antiguo en la estación → borra los datos del navegador de la
    Quest y recarga.
  · La TV no conecta → ¿relay encendido? ¿?relay= correcto?
  · Más ayuda: LEEME-DESPLIEGUE.txt dentro del paquete.
